This learning track turns numbers into decisions: chance, collected facts, charts, and a first look at how computers count in zeros and ones.

Learners measure how likely an event is, gather and summarize data, choose an honest picture for those facts, and see the same place-value idea wearing a binary costume.

Optional enrichment: connect those same ideas to news charts, fair game chance, and computer bits in daily life.
