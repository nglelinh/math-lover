## Hook

A game lets you pick **2 hats**, **3 shirts**, and **2 shoes**.

How many characters can you make?

If you pick at random, you might skip one pair. Systematic counting — hat first, then shirt, then shoes — finds every outfit once.

## Discovery Puzzle

Hats: A, B. Shirts: 1, 2, 3.

List every pair. How many?

Now add shoes: red or blue. Do you add 2, or multiply by 2? Why?

---

## Core Idea

When choices happen **in a row**, multiply.

$$2 \times 3 \times 2 = 12$$

Khan Academy’s colour-code example uses the same “fill each slot” picture.

### Password length, plainly

A door code with 3 digits, each 0–9, has 10 choices per slot:

$$10 \times 10 \times 10 = 1000$$

Four digits:

$$10 \times 10 \times 10 \times 10 = 10000$$

Longer codes make a longer list. That is why grown-ups ask for longer passwords — not because of mysterious adult machines, but because **more slots mean more outfits**. We do not study breaking codes here. We only count.

![A combination lock with numbered slots](https://upload.wikimedia.org/wikipedia/commons/b/be/Combination_Lock.svg)

*Image: Wikimedia Commons*

Scratch character costumes work the same way: pick a look, then a backdrop, then a sound. Each extra menu multiplies the show.

If the menu says “pick soup **or** salad” (one dish only), you **add**. If it says “pick soup **and then** a drink,” you **multiply**. That is the same or/and rule from the core Chapter 9 lessons, now printed on a game screen.

## Guided Discovery Activities

### Activity 1: Paper dolls

Cut 2 hats and 3 shirts. Glue every pair on a grid. Check 6.

### Activity 2: Ice-cream menu

2 cones and 4 scoops. Tree: cone first. How many sundaes?

### Activity 3: Short family code

Invent a 2-shape code using ○ and △ only. List all 4 codes. Then add a third slot. How many now?

## Example Walkthrough

Avatar menu: 4 hairs × 2 glasses × 3 pets.

$$4 \times 2 \times 3 = 24$$.

If glasses are optional (wear / not wear), that is still 2 choices in that slot.

## Thinking Questions

1. When do you add menus (this **or** that) instead of multiplying?
2. Why does a table beat a messy brain list?
3. If order does not matter (a team of two friends), why is $$3 \times 2$$ too big?

## Parent Corner
