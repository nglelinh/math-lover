## Khám phá toán học

### Cộng số thập phân

**Bước 1:** Viết các số thẳng cột (dấu phẩy thẳng nhau)
**Bước 2:** Cộng như cộng số tự nhiên
**Bước 3:** Hạ dấu phẩy xuống kết quả

**Ví dụ:** 12,5 + 7,3 = ?
```
  12,5
+  7,3
------
  19,8
```

### Trừ số thập phân

**Ví dụ:** 15,7 - 8,4 = ?
```
  15,7
-  8,4
------
   7,3
```

### Trường hợp đặc biệt

**Khi phần thập phân không bằng nhau:**

**Ví dụ:** 8,5 - 3,25 = ?
```
   8,50   (thêm 0 vào 8,5)
-  3,25
------
   5,25
```

### Hoạt động 2: Trừ số thập phân

Tính:
- 9,5 - 4,3 = 5,2
- 10,0 - 3,75 = 6,25

### Hoạt động 3: Giải toán

Lan mua vở hết 12.500 đồng và bút hết 7.500 đồng. Hỏi Lan mua hết tất cả bao nhiêu tiền?

**Giải:** 12.500 + 7.500 = 20.000 đồng
