# AGENTS.md

High-signal operating notes for AI agents in `math-lover`.

## Read First
- Apply all rules in `.cursor/rules/` (`lecture-notes-rule.mdc`, `math-formula-rule.mdc`, `course-books-rule.mdc`, `illustration-rule.mdc`) for lesson/content work.
- This repo has no `.github/copilot-instructions.md` and no repo-level `opencode.json`.

## What This Repo Actually Is
- Jekyll site with custom plugins, bilingual lesson content, and vanilla JS (no bundler, no TypeScript).
- Core content lives in `contents/en/` and `contents/vi/`; chapter posts are under `chapterXX/_posts/`.
- Deploys via `.github/workflows/jekyll.yml` to GitHub Pages.

## Commands That Matter
- Install + local dev: `bundle install && bundle exec jekyll serve --livereload`
- Fast build check: `bundle exec jekyll build`
- CI-parity check (important): `python3 scripts/check_vi_interactive_coverage.py && JEKYLL_ENV=production bundle exec jekyll build --baseurl "/math-lover"`
- Plugin syntax checks: `ruby -c _plugins/multilang.rb && ruby -c _plugins/multilang_post_url.rb && ruby -c _plugins/redirect_generator.rb`
- Single Python file syntax check: `python3 -m py_compile path/to/script.py`

## Non-Obvious CI Gate
- CI runs `scripts/check_vi_interactive_coverage.py` before Jekyll build.
- If you add/edit a Vietnamese lesson post, keep `_data/vi_interactive_lessons.json` in sync and include:
  - `<!-- vi-interactive:start -->`
  - `{% include vi-interactive-lesson.html %}`
  - `<!-- vi-interactive:end -->`
- Missing mapping/include will fail CI.

## Content Conventions That Break Easily
- Lessons are expected in both languages (`en` + `vi`) for equivalent content additions.
- Front matter used across lessons: `layout`, `title`, `chapter`, `order`, `owner`, `lang`, `categories`, `lesson_type`.
- Use chapter categories like `chapter01`.
- Use `$$...$$` for math; avoid inline `$...$` in this repo.
- Use `{{ site.baseurl }}/img/...` for image paths (GitHub Pages baseurl is required).

## Template / Plugin Wiring You Should Know
- Custom Liquid tags come from `_plugins/multilang.rb` and `_plugins/multilang_post_url.rb`: `{% t %}`, `{% language_switch %}`, `{% multilang_post_url %}`.
- Redirect pages are generated by `_plugins/redirect_generator.rb`.
- In `_layouts/post.html`, Vietnamese posts load shared `public/js/interactive-vi-lessons.js`; EN chapter-specific interactives are only auto-loaded for chapters `01`, `02`, and `04`.

## Validation Expectations
- No formal unit-test suite is configured; primary gate is successful Jekyll build + targeted manual page checks.
- For UI/content changes, manually verify: language switch, page rendering, MathJax rendering, and image links.
- Never commit build artifacts from `_site/`.
